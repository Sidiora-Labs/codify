codify.

The agent workflow tool that scales from small, simple projects to large, complex codebases. One binary, 100% local.

install or update (Linux x86_64)

curl -fsSL https://codify.centra.ag/install | bash

then, in any project

cg init # graph + snapshots cg context "auth" # one-call context for agents cg mcp-install # connect Claude Code, Cursor, VS Code, ... cg spec # task board, verified done

uninstall

curl -fsSL https://codify.centra.ag/uninstall | bash

Source, docs, and other platforms: github.com/sidiora-labs/codify
